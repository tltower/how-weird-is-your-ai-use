# Anthropic source data

This directory pins the `stanford_clusters.csv` and `metr_clusters.csv` files from Anthropic's
[`enabling-independent-research`](https://huggingface.co/datasets/Anthropic/enabling-independent-research)
release. The release is licensed under CC BY 4.0 and describes a fixed April–May 2026 sample.

The application uses only aggregated cluster labels, descriptions, counts, and ratios. It does not
contain Anthropic conversation records.
